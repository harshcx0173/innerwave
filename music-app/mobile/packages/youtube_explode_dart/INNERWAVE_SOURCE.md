# InnerWave source note

This package was copied from `packages/youtube_explode_dart` in
[`gokadzev/Musify`](https://github.com/gokadzev/Musify) at commit
`5b98d3a3cddd3fdb16ea6cc14d59d667e82cccd2`.

Only the runtime library, package manifest, README, and original BSD-3-Clause
license are vendored. InnerWave uses Musify's current `visionOs` YouTube client
support so stream manifests are resolved on the listener's device instead of a
cloud-hosted IP address.
